# TPEX API Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a TPEX reader for mainboard OTC stocks, emerging stocks, and OTC index data.

**Architecture:** Create `sources/tpex` alongside `sources/twse`. Keep the shared `Reader` interface unchanged and route symbols inside the TPEX reader by symbol format.

**Tech Stack:** Go, `net/http`, `encoding/json`, existing `internal/http` retry client, repository test helpers.
